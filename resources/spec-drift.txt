# Corpus documents this gem is KNOWN to render differently from spec main.
#
# WHAT THIS FILE IS FOR
#
# The engine inside this gem is pinned. The spec is not. When a rule lands in
# markup-carve/carve, carve-rs implements it some time later and this gem picks
# it up later still, when ext/carve/Cargo.toml moves. Until then the gem renders
# those documents by the older rule, and the corpus comparison against spec main
# says so. That window is normal and the drift report exists to describe it.
#
# So the window is DECLARED rather than tolerated. Every document listed below
# is a divergence somebody looked at and wrote down. A divergence that is NOT
# listed is the state nobody knows they are in - a pinned build rendering
# documents wrongly with nothing saying so (markup-carve/carve-rb#100,
# following the split ruled in markup-carve/carve#1811). It arrives as a pull
# request adding the row, not as a red build.
#
# HOW IT IS ENFORCED
#
#   per-PR CI     a declared document that NO LONGER DIVERGES fails. The ledger
#                 describes this gem, so a row its own measurement contradicts
#                 is this repository disagreeing with itself, and deleting the
#                 row is an action taken here.
#   the schedule  an UNDECLARED diverging document opens a pull request that
#                 adds it here, rather than reddening `main`. The spec gains
#                 documents faster than this pin moves, so that reading used to
#                 return to red by design and blocked unrelated pull requests
#                 (markup-carve/carve#2706, markup-carve/carve-rb#157).
#                 scripts/declare-spec-drift.sh writes those rows.
#   release gate  this file must be EMPTY. A declared window is a window that is
#                 still open, and a tag must not ship one.
#
# The clearing action for both is taken in THIS repository: bump the carve-rs
# revision in ext/carve/Cargo.toml, commit the regenerated ext/carve/Cargo.lock,
# and delete the rows the bump closed.
#
# FORMAT
#
# One corpus document basename per line, without the .crv extension, as
# scripts/verify-packaged-gem.rb prints it. Anything after `#` is the REASON,
# and it is REQUIRED - a row without one is refused. Blank lines are ignored.
#
#   367-002  # spec gained `{=raw}` on attribute lines; carve-rs has not shipped it
#
# A REASON THAT IS ABOUT THE PIN MUST NAME THE PIN. The wording "the pinned
# engine predates it" is true only while the gem pins that engine, and it was
# false for 21 rows the moment one bump landed (markup-carve/carve-rb#167). So
# it is written with the pin in it and the gate expires it when the manifest
# moves:
#
#   367-002  # undeclared at spec main abc1234 on 2026-10-07; the pinned engine carve-lang 0.1.8 predates it
#
# scripts/declare-spec-drift.sh writes that form. When the gate reports a row
# as expired, delete it if the bump closed the window, and record the real
# reason if it still diverges - do not restore the old wording with a new pin.
#
# EMPTY IS THE GOAL STATE. An empty file means this gem renders every document
# in spec main exactly as the spec does, and it is the only state that may be
# tagged.
